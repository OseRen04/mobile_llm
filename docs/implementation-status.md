# 実装・受け入れ状況

確認日：2026-11-18（日本時間）。本実装は実験版です。仕様の製品化条件すべてが完了した状態ではありません。

## 実装済み

- React / TypeScriptのPWAと、共通UI・翻訳コアを使うManifest V3拡張。
- ja/en/ru全6方向。日露は英語経由。実モデルq8をWorker内のCPU/WASMで実行。
- 入力2,000 Unicode code points、実トークナイザで特殊トークン込み192 tokens以下への分割。中間英語も再分割。
- 取得前確認、ファイル単位の進捗・中断・再取得、モデル状態・削除、容量確認。
- 固定revision・実サイズ・SHA-256を保存前に確認。本文を含まない固定URLのGETのみ。
- モデルキャッシュとアプリシェルを分離。WASM/JSはローカル配布。Workerのリモートモデル取得は無効。
- 逐次ロードによるメモリ抑制、Worker終了によるキャンセル、古いWorkerイベント無視、完成前の結果を確定しない。
- 原文・訳文の分離、訳文編集・コピー代替操作・方向入替・クリア・再試行。本文の永続保存なし。
- 最小権限の入力欄取得・選択部分の確認付き置換。変更検出・危険欄除外。フォーム送信なし。
- lockfile、CI、単体・UI・実モデル・拡張ブラウザテスト、ライセンスnotice。

## 製品化前に残る検証

1. iPhone Safari/Chrome、Android Chromeの実機で推論、コピー、インストール、タブ破棄・復帰、メモリと容量を測る。
2. 自作セットの重大な意味誤りを改善し、母語話者の評価を得る。現状は全ペア実験的対応であり、P0の品質ゲートは未達。
3. 30/100/500文字、p50/p95、ロード・推論・ピークRAMを分けた性能評価。現デスクトップ実測からスマホの速度は保証しない。
4. OS／ブラウザ再起動とストレージ削除を含め、モバイルでオフライン利用を確認する。
5. 拡張ツールバーからのactiveTab許可、実サイトの管理フォーム、拡張内の実モデル翻訳、Chrome Web Storeの配布条件・審査を確認する。

q4比較は品質・互換性評価後の追加項目として未実装。WebGPU・履歴・用語集・課金・クラウド同期は実装していません。
